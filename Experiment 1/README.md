# Experiment 1 — E-commerce ER Diagram

## Aim
Design an ER diagram for an Indian e-commerce platform containing Customer, Address, Order, OrderItem, Seller, Product, Category, Payment, and Delivery. The diagram demonstrates keys, a multivalued attribute, a weak entity, product specialization, cardinalities, and participation constraints.

## ER notation used
- Rectangle: strong entity; double rectangle: weak entity.
- Oval: attribute; double oval: multivalued attribute; underlined attribute: primary key.
- Diamond: relationship; double diamond: identifying relationship; triangle: ISA/specialization.
- `1:1`, `1:N`, and `M:N`: relationship cardinalities.

## Artifact and output
The original experiment file is included unchanged as [`Experiment_1_ER_Diagram.pdf`](Experiment_1_ER_Diagram.pdf). It contains the ER diagram and its stated result: the e-commerce ER model includes the required entities, attributes, relationships, cardinalities, weak entity, multivalued attribute, and product specialization.

## Implementation
This is a conceptual modeling experiment. Its deliverable is the ER diagram; the relational implementation is in Experiment 2.
